## Phase 7 部分: redact pattern 拡充

DR-0009 Phase 7 の対象に「redact pattern 拡充」がリストされていた:

> Slack token (xox[abpr]-...) / Stripe sk*live* / GCP service account key /
> OpenAI sk-proj- sk-svcacct- / generic (API\_)?KEY|SECRET|PASSWORD|TOKEN env 名

codex review でも CONCERN 5 として指摘済み。Phase 1 補強の時点では「Phase 7 で
扱う」と journal で保留したが、純技術判断 + 安全側 (false positive 増えても被害
なし) なので前倒し実装。

### 追加 pattern

| pattern                     | 検出対象                                                                                 |
| --------------------------- | ---------------------------------------------------------------------------------------- |
| `OPENAI_API_KEY_NEW`        | `sk-proj-...` / `sk-svcacct-...` / `sk-admin-...` (新形式)                               |
| `GITHUB_PAT_FG`             | `github_pat_...` (fine-grained PAT)                                                      |
| `SLACK_TOKEN`               | `xoxb-` / `xoxp-` / `xoxa-` / `xoxr-` / `xoxs-`                                          |
| `STRIPE_KEY`                | `sk_live_` / `pk_live_` / `rk_live_` / sk/pk/rk*test*                                    |
| `GENERIC_API_KEY_ENV` 拡張  | `SLACK_TOKEN` / `SLACK_BOT_TOKEN` / `STRIPE_SECRET_KEY` / `STRIPE_API_KEY` 追加          |
| `LOOSE_CREDENTIAL_ENV` 新規 | `<ALL_CAPS>_(API_KEY\|SECRET_KEY\|PRIVATE_KEY\|ACCESS_KEY\|PASSWORD\|TOKEN\|SECRET)=...` |

### 設計判断

- **OpenAI 新形式 (sk-proj-) を sk- ジェネリックより前に置く**: 新形式は body
  に `-` / `_` を含む、strict な sk-[A-Za-z0-9]{20,} で先にマッチさせると body
  が途中で切れる。順序で specificity 確保
- **LOOSE pattern に negative lookahead `(?!\[REDACTED)`**: GENERIC_API_KEY_ENV
  が先に `<NAME>=[REDACTED]` に正規化した値を LOOSE が再マッチして count++
  していたバグを修正
- **GCP service account JSON は単体 regex で検出困難**: JSON 構造 (= 改行 +
  キー名 `"private_key": "-----BEGIN PRIVATE KEY-----...` 等) を含む。SSH_PRIVATE_KEY
  pattern が `-----BEGIN PRIVATE KEY-----` block を捕捉済なので key 本体は既に
  redact 済。json wrapper の他フィールド (`client_email` 等) は secret ではない
  ので redact 対象外。よって追加 pattern 不要と判断

### 検証

`redact.test.ts` に 12 件追加:

- OpenAI sk-proj- / sk-svcacct- (2 件)
- github*pat* (1 件)
- Slack 5 prefix variants (2 件)
- Stripe live/test key + 4 variants (2 件)
- loose pattern: MY_SERVICE_API_KEY / DATABASE_PASSWORD / INTERNAL_API_TOKEN (3 件)
- GENERIC_API_KEY_ENV 拡張 (SLACK_BOT_TOKEN) (1 件)
- loose pattern 短すぎ NAME 否定 (1 件)

全 test pass (40 件 in redact.test.ts、全体 822 件 pass)。
